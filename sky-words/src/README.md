# Sky Words — Kanban-доска задач

Проект **"Sky Words"** — это приложение для управления задачами в формате Kanban-доски.

---

## 🌟 Основной функционал

## Функционал
- Добавление, редактирование и удаление задач
- Группировка по статусам
- Подтверждение удаления
- Обработка сетевых ошибок
- Валидация полей

## Дополнительные "фичи"
- Выпадающее меню на карточке (три точки)
- Редактирование с URL-параметром `?edit=true`
- Защита от пустых и пробельных полей
- Анимации загрузки
- Страница 404
